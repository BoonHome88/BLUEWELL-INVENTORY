BLUEWELL OFFLINE SCANNER

การใช้งาน
1. เปิดไฟล์ index.html ด้วย Google Chrome หรือ Microsoft Edge
2. ใน BlueWell Inventory ไปที่หน้า “สินค้า” แล้วกด “ส่งสินค้าไปเครื่องออฟไลน์”
3. กลับมาหน้า “รายการสินค้า” ของโปรแกรมออฟไลน์ แล้วนำเข้าไฟล์ที่ได้
4. ใช้หน้า “เบิกสินค้า” ยิงบาร์โค้ด กรอกจำนวน และหมายเหตุ
5. กด “ส่งออกไฟล์เบิก .xlsx”
6. ใน BlueWell Inventory เปิดเมนู “นำเข้าเบิกออฟไลน์” เลือกไฟล์ ตรวจสอบ และยืนยันตัดคลังกลาง

หมายเหตุ
- โปรแกรมนี้ไม่ต้องเชื่อมอินเทอร์เน็ต
- ข้อมูลเก็บในเบราว์เซอร์ของคอมเครื่องนี้ ห้ามล้างข้อมูลเว็บไซต์ก่อนส่งออกไฟล์
- ใช้เครื่องยิงบาร์โค้ด USB ที่ทำงานเหมือนคีย์บอร์ดได้
- เมื่อนำเข้าไฟล์เบิกบนเว็บสำเร็จ ไฟล์ชุดเดิมจะไม่สามารถนำเข้าซ้ำได้
